# Plumbers on Call Corp

Temporary company homepage built with Next.js, React, TypeScript, and the App Router.

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

The project is ready for Git-based or CLI deployment to Vercel. The intended canonical production domain is `https://plumberoncallcorp.com`.
